# Getting Started

This starter site is meant to be edited, rebuilt, and explored quickly.

## Suggested First Steps

1. Update site_title and site_tagline in kujo-ssg.yml.
2. Edit one page and one post under content.
3. Build and inspect output for structure and SEO tags.

## Where To Customize

- templates/layout.html controls shared chrome.
- templates/page-home.html controls home listing layout.
- templates/page-blog.html controls blog listing layout.
