# About This Starter

This project is a practical static site generator starter built in Kujo.

It is designed to mimic a real publishing workflow with markdown content, templates, taxonomy lookups, and production-style output.

## What It Demonstrates

- Frontmatter parsing.
- Markdown to HTML conversion.
- Multi-template rendering.
- Asset copying into a public output folder.
- Shared and content-type-specific taxonomy lookup behavior.
